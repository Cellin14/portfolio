# Gestion des employés

Application PHP/MySQL de gestion des employés : authentification, employés, salaires, présences, rapports et préférences.

## Installation

1. Importer `schema.sql` dans MySQL.
2. Copier `.env.example` vers `.env` et définir les variables dans l’environnement PHP/serveur (ne pas committer `.env`).
3. Servir le dossier `gestion/` avec PHP et ouvrir `connexion.php`.

Les identifiants de base de données et d’administration ne sont volontairement pas stockés dans le code public.
